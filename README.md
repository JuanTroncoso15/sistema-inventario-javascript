# Sistema de Inventario Básico con JavaScript

## Descripción

Este proyecto corresponde a la primera semana de la actividad académica de preparación del entorno para desarrollo e integración continua. Consiste en una aplicación web sencilla para gestionar un inventario, con almacenamiento local en el navegador y pruebas automatizadas en Node.js.

## Objetivo

Permitir registrar productos, consultar el estado del inventario, editar registros, eliminar elementos, buscar artículos y calcular el valor total disponible en el almacén.

## Tecnologías utilizadas

- JavaScript
- HTML5
- CSS3
- Node.js
- Git
- GitHub
- GitHub Actions

## Requisitos

- Node.js 20 o superior
- npm
- Un navegador moderno

## Instalación

1. Clona o descarga este repositorio.
2. Accede a la carpeta del proyecto:
   ```bash
   cd sistema-inventario-javascript
   ```
3. Instala las dependencias:
   ```bash
   npm install
   ```

## Ejecución local

```bash
npm start
```

Luego abre la dirección local indicada por `http-server`, normalmente en `http://localhost:8080`.

## Pruebas automatizadas

```bash
npm test
```

## Verificación de sintaxis

```bash
npm run check
```
